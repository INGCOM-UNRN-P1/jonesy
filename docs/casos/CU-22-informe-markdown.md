# CU-22 · Escribir el informe en Markdown

**Actor:** Alumno · **Grabación:** [`CU-22-informe-markdown.cast`](CU-22-informe-markdown.cast) (0:13) · **En la lista de casos:** [CU-22](../casos_de_uso.md#cu-22--escribir-el-informe-en-markdown)

## De qué se trata

Los `.md` se editan con resaltado y **Ctrl+P** abre la vista previa dibujada al lado:
títulos, tablas, listas, código y enlaces (que se recorren con Tab). La vista se
actualiza mientras se escribe.

## Qué muestra la grabación

| Tiempo | Paso |
|---|---|
| 0:00 | El informe en Markdown, con resaltado |
| 0:02 | Ctrl+P: la vista previa dibujada al lado |
| 0:04 | La vista se actualiza mientras se escribe |

## Cómo verla

```bash
asciinema play docs/casos/CU-22-informe-markdown.cast        # de corrido
asciinema play -m docs/casos/CU-22-informe-markdown.cast     # se detiene en cada paso (Espacio sigue)
```

Las pausas largas (compilar, esperar al programa) se acortan a 2 s al reproducir. La grabación se hizo con el proyecto de demostración de [`grabador/demo`](grabador/demo) en una terminal de 132×36.
